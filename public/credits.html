设计来源

页面采用本地 ReEndfield 风格库中的语义色彩、纸面与墨面分区、字体角色和工程网格关系。页面排版、图标、三维地形、动态线框、设备示意与歌词视觉均为本主页独立实现，没有使用游戏官网脚本、角色立绘、Logo 或研究截图。

ReEndfield 是独立研究与原创实现库，不是《明日方舟：终末地》官方设计系统。相关名称与商标归各自权利人所有；本站与游戏开发商无关联。

开放字体

Space Grotesk 用于拉丁字形与编号；Noto Sans SC 用于中文；IBM Plex Mono 用于命令。实时日语歌词使用 Noto Sans JP，并按所选 LRC 字形子集化。字体从 ReEndfield 的开放资产目录取得，本地提供，不请求第三方字体服务。中文字体按本站文本子集化，保留原有字形。原始字体许可如下：

  • Space Grotesk · SIL OFL 1.1
  • Noto Sans SC · SIL OFL 1.1
  • IBM Plex Mono · SIL OFL 1.1
  • Noto Sans JP · SIL OFL 1.1

技术与内容

基于 Vite、TypeScript 与 Three.js 构建，由 GitHub Pages 托管。Three.js 遵循 MIT 许可。所有工具介绍均依据对应项目的 README 与本地实现资料整理；设备图与文件窗口是原创视觉示意，不是真实运行截图。Lyrscape 体验复用项目的 MIT 许可生产文字渲染器、歌词解析器和时间轴，只适配网页字体和样式作用域。固定《arrow》LRC 来自站点所有者提供的本机文件，音频不随网站打包。音乐与歌词的权利归各自权利人。无声预览与真实音频播放有明确区分；网易云外链不可用时，可选择自己的音频，在浏览器本地同步。

隐私

本站不包含统计脚本、广告、登录或追踪器。浏览器只在本机保存动态背景的开关偏好。点击网易云试听会访问网易云音源；选择本地音频仅创建本机浏览器对象地址，不会上传文件。BakoPacker 完整编辑器只在主动启动后载入。点击外链或载入第三方页面后，适用目标网站的隐私规则。
