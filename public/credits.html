设计来源

页面采用本地 ReEndfield 风格库中的语义色彩、纸面与墨面分区、字体角色和工程网格关系。页面排版、图标、三维地形、动态线框、设备示意为本主页独立实现，歌词视觉复用 Lyrscape 的 MIT 许可实现，没有使用游戏官网脚本、角色立绘、Logo 或研究截图。

ReEndfield 是独立研究与原创实现库，不是《明日方舟：终末地》官方设计系统。相关名称与商标归各自权利人所有；本站与游戏开发商无关联。

ReEndfield 原创实现许可

Lyrscape 代码许可

开放字体

Space Grotesk 用于拉丁字形与编号；Noto Sans SC 用于中文；IBM Plex Mono 用于命令。歌词渲染字体见下方专节；界面字体从 ReEndfield 的开放资产目录取得，本地提供，不请求第三方字体服务。中文字体按本站文本子集化，保留原有字形。原始字体许可如下：

  • Space Grotesk · SIL OFL 1.1
  • Noto Sans SC · SIL OFL 1.1
  • IBM Plex Mono · SIL OFL 1.1
  • Noto Sans JP · SIL OFL 1.1

技术与内容

基于 Vite、TypeScript 与 Three.js 构建，由 GitHub Pages 托管。Three.js 遵循 MIT 许可。所有工具介绍均依据对应项目的 README 与本地实现资料整理；设备图与文件窗口是原创视觉示意，不是真实运行截图。Lyrscape 体验采用晴空终端 III 的生产 canvas 渲染器、歌词解析器和时间轴。无声预览与真实音频播放有明确区分。

本站源码 · Three.js 许可

隐私

本站不包含统计脚本、广告、登录或追踪器。浏览器只在本机保存动态背景的开关偏好。歌词展示会访问塞壬唱片的公开歌词 CDN；点击网易云试听会访问网易云音源；选择本地音频仅创建本机浏览器对象地址，不会上传文件。BakoPacker 完整编辑器只在主动启动后载入。点击外链或载入第三方页面后，适用目标网站的隐私规则。

Lyrscape 晴空终端 III 与音乐

歌词 parser、timeline、PV stage、晴空终端 III 与其绘制依赖来自 Lyrscape，以 MIT 许可使用。Web 适配与逐文件来源见站点源码内 PROVENANCE.json；MIT 许可原文。

《Heavenly Me》由 AIYUE blessed : 理名演唱，塞壬唱片-MSR 发行。试听使用网易云官方外链，歌词从塞壬唱片官方歌曲页对应的公开歌词地址即时载入；本站不托管歌曲音频，也不再打包歌词全文。歌曲与歌词版权归原权利人所有。

晴空终端 III 使用原项目同款 Noto Sans JP、Fusion Pixel 12px Proportional JP、Share Tech Mono。字体为 SIL OFL 1.1：Noto、Fusion Pixel、Share Tech Mono。视觉参考源与原项目相同，不使用 PV 截帧。
